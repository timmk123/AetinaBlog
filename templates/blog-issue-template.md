# 每篇 Blog 文章的 Linear Issue 模板

每個月主題確定後，在 Linear「Tech Blog」project 建立新 milestone（milestone 名稱＝當月主題），
並在該 milestone 下建立以下 6 個固定 issue：

1. 主題與大綱確認 — 確定展覽名稱、想涵蓋的技術重點、是否要拆多篇
2. 素材蒐集 — 找齊圖片、影片、簡報等素材，放入 `assets/`
3. 撰寫初稿 — 完成 index.md 概述、技術細節、問題與解法、成果心得
4. 內部審閱 — 找人看過內容/技術正確性
5. 素材整理與優化 — 圖片壓縮、影片剪輯、加浮水印（如需要）
6. 發布 — frontmatter status 改 published，正式發布
